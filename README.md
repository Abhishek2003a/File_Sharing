# 📂 File Sharing Web App

A simple and efficient **File Sharing Web Application** that enables users to **upload, store, and download files** easily and securely.  
This project is built using **React.js** for the frontend and **Node.js + Express.js** for the backend, with support for multiple file types like `.png`, `.jpg`, `.pdf`, `.mp4`, `.docx`, and more.

---

## 🚀 Features

- 📤 **Upload Files:** Upload any type of file (images, videos, documents, etc.)
- 📥 **Download Files:** Download your uploaded files with their **original type and format** preserved.
- 🔒 **Secure File Storage:** Files are stored safely on the server using unique IDs.
- ⚡ **Fast & Reliable:** Optimized upload/download flow with instant feedback.
- 🧠 **MIME-Type Handling:** Automatically detects and serves correct file types.
- 🧾 **Clean UI:** Minimal and user-friendly interface.

---

## 🛠️ Tech Stack

**Frontend:**

- React.js
- Tailwind CSS

**Backend:**

- Node.js
- Express.js
- Multer (for file uploads)

**Storage:**

- Local server (can be extended to cloud storage like AWS S3 or Cloudinary)
